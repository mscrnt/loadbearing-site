Privacy Policy

EFFECTIVE 2026-06-22 · APPLIES TO LOADBEARING.GAMES AND THE LOAD BEARING GAME (STEAM APP 4883800)

The short version

Load Bearing is a single-player game. It is fully playable offline. If — and only if — you opt in, the game sends anonymous gameplay telemetry to a server we run ourselves. No personal information is ever collected: no name, no email, no IP, no Steam ID, no machine identifier, no save filename, no text you type. You can opt out at any time. Opt-out is the default.

Who runs this

"Load Bearing", loadbearing.games, and the Steam release are operated by mscrnt (the "developer"). Contact: hello@loadbearing.games.

What the website (loadbearing.games) collects

Nothing. The site is a static page hosted on Cloudflare Pages. It sets no cookies, has no analytics scripts, embeds no third-party trackers, and runs no JavaScript that contacts other services. Cloudflare may keep edge-level request logs (IP, user-agent, URL) as part of its standard DDoS/abuse protection — those logs are governed by Cloudflare's own privacy policy and the developer does not access or retain them.

What the game collects — only if you opt in

On first launch you'll see a clear, plain-language consent prompt. It defaults to OFF. If — and only if — you choose to opt in, the game records gameplay events and periodically uploads them in batches to a server we operate.

Each event carries:

  • The event type (e.g. "map_attempt", "session_start", "node_bought").
  • An ISO timestamp.
  • The game version and the balance version currently running.
  • Three random anonymous UUIDs: one per install ("anon_id"), one per launch ("session_id"), one per run ("run_id"). These are generated locally with no relationship to your identity, your operating system account, or your Steam account. We do not back them up to the cloud, and they are not synced across devices or reinstalls.
  • Per-event gameplay properties — things like map index, attempt count, outcome, time to clear, clicks-per-second aggregates, currency earned/spent. The full list of event types and their properties is published in our open privacy notice on this site; we will update it as new event types are added during Early Access.

What we do not collect, ever:

  • Your name, email, address, phone number, or any account identifier.
  • Your IP address. The ingest server is explicitly configured to drop any client IP, User-Agent, and proxy header before storage.
  • Your Steam ID, Discord ID, or any social-platform identifier.
  • Your operating-system username, machine name, hardware fingerprint, save-file name, or any string you type in-game.
  • Anything outside the in-game gameplay loop. We do not read other files, monitor other applications, or do anything outside the game's own sandbox.

Why we collect it

The single purpose is game balance — the difficulty curve, where players quit, which builds win, whether a balance patch helped or hurt. Real-player data is the only way to validate that the game is fun at scale; without it, every balance change is a guess. The data is never used for advertising, never sold, never shared with third parties, and never used to identify anyone.

Where it's stored and how long

Events flow through a Cloudflare Tunnel to a Vector ingest service to a ClickHouse database. All three run on hardware the developer owns and physically controls. No third-party data processors are involved. Events are kept for a maximum of 13 months, after which they are automatically deleted by a retention policy in the database. We may aggregate the data into anonymous summaries (e.g. "average attempts to clear map 7 in version 0.4.x") and keep those aggregates indefinitely — the aggregates contain no per-player rows.

How to opt out

In the game, open Settings → Privacy → Telemetry. Set the switch to OFF. The game will immediately stop collecting events, drop any queued events not yet sent, and abort any upload in flight. The next launch will respect the OFF setting.

If you want past events that were sent under your install's anon ID forgotten: because the data is fully anonymous and not keyed to anything we can re-identify, we cannot reliably delete "your" rows on request. You can, however, flip opt-out and delete the game's user-data folder (which deletes your "anon_id"); from that moment, no new events are linkable to you. Email hello@loadbearing.games for help.

Your rights

Depending on where you live (GDPR in the EU/UK, CCPA in California, similar laws elsewhere), you have rights including access, correction, deletion, and consent withdrawal. Because we collect no personally identifying data, most of these rights are satisfied by the opt-out switch above. For anything else, email hello@loadbearing.games and we will respond within 30 days.

Children

Load Bearing is not directed at children under 13 (or under 16 in jurisdictions where that's the relevant age). The telemetry consent prompt is plain language, but we do not knowingly collect data from children. If you believe a child has opted in to telemetry on your device, email us and we'll explain how to clear the local anon_id.

Changes to this policy

If the data we collect or the way we handle it changes, we will update this page and bump the "effective" date at the top. For material changes (adding a new event type, changing retention, anything new), the game's consent prompt will re-trigger so you can re-confirm.
